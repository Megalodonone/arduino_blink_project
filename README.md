# Arduino Blink Project

Проект: мигание светодиода на Arduino Uno.

Сначала я отработала схему в симуляторе Wokwi, а затем собрала её на реальной макетной плате. Это помогло убедиться, что все соединения корректны и компонент подобран верно.
![Схема в Wokwi](wokwi_scheme_blink_1.png)

**Что использовано:**
- Плата Arduino Uno
- Красный светодиод
- Резистор 220 Ом

**Фото реальной сборки:**

![Реальная сборка на макетной плате](photo1.jpg)

**Как запустить:**
1. Открыть скетч `blink.ino` в Arduino IDE.
2. Выбрать плату: Arduino Uno.
3. Загрузить скетч на плату.
